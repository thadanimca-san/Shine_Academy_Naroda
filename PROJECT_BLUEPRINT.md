=========================================================
TRILINGUAL ARCHITECTURE (THE SHINE ACADEMY WAY)
=========================================================

Shine Academy Naroda is built for Indian students. English alone is not enough. We are a Trilingual Platform.
"We are not Angrejo ki aulad."

1. All educational content must support English (en), Hindi (hi), and Gujarati (gu).
2. The platform must allow the user to select their primary learning language upon first launch.
3. A Trilingual Toggle Button must be universally available (docked or in the App Bar) allowing students to instantly switch the current screen to their preferred language.
4. If a translation is missing, the platform must gracefully fallback to English without breaking.
5. All future modules, JSON schemas, and widgets MUST support these translation keys natively.
