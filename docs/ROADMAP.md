# Roadmap

## Phase 1
**Core Platform**
- Project initialization and folder structure.
- Routing (GoRouter) and basic Navigation.
- Profile Selection (Role, Stage, Class, Board).
- UI Theming (Material 3, custom fonts, AppColors).
- PDF Generation Engine with custom watermark and Rupee symbol support.

## Phase 2
**Learning System**
- Curriculum mapping via JSON.
- Chapter details UI (Tabs: Theory, Examples, Exercises, PYQs).
- Dynamic Language Toggle (English / Gujarati).
- Generation of the "Mahabharat" level comprehensive curriculum data for Class 11 & 12 Commerce.
*(Currently In Progress)*

## Phase 3
**Assessment**
- Interactive Quizzes.
- Score tracking and progress analytics.
- Mock Tests for Board Exams.

## Phase 4
**Community**
- Peer-to-peer discussion forum.
- Doubt solving section.

## Phase 5
**Teacher Panel**
- Teacher-specific dashboard.
- Analytics on student performance.
- Custom quiz creation.

## Phase 6
**Parent Dashboard**
- Activity monitoring.
- Progress reports.

## Phase 7
**Early Childhood Education**
- Expand curriculum to Jr KG and Sr KG.
- Gamified learning tailored for toddlers and early learners.

## Phase 8
**AI Tutor**
- Chat interface for AI-powered doubt resolution.
- Personalized learning recommendations.
